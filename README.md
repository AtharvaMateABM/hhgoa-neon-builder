# HH Goa 2026 Neon Builder ID

Updated black + neon theme for the Hacker House Goa 2026 builder generator.

## Changes
- Black / neon visual theme
- New Orbitron display typography
- Name centered in the card
- QR code contains all builder information
- Seven photo-position presets
- Fine X/Y/zoom positioning controls
- One photo only per generation
- Replace/remove photo workflow
- Real QR generation
- PNG export includes the QR code
- Responsive layout

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

For production:

```bash
npm run build
npm start
```
